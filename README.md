# Fusion-Footwear-Website
Fusion Footwear is a responsive e-commerce website project designed to showcase footwear products, including sneakers, casual shoes, formal shoes, and sports shoes. Built using HTML, CSS, and JavaScript, the website features product search, category filtering, price sorting, and an interactive shopping bag with subtotal calculation. 
# Fusion Footwear Website

A modern, responsive footwear storefront created as a web development college project.

## Features
- Responsive website layout
- Footwear product catalogue
- Product search and category filtering
- Price sorting
- Interactive shopping bag
- Subtotal calculation
- Newsletter form demonstration

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Status
Frontend demonstration project. Backend integration, database storage, user authentication, and real payment processing are not included in the current version.

## How to Run
1. Clone or download this repository.
2. Open `Fusion_Footwear_Website.html` in a web browser.
3. Explore the products and test the available interactive features.
